# 扫描教材实证问题

- 双栏练习题中，选项 b/d 与 a/c 同行但 x 偏移。按“短行且偏离正文边缘”过滤，会无声删除正确选项。
- 全宽的章节测验横条可能只有左侧短标题被 OCR 识别；文字框不宽不代表标题不跨栏。须看原图后配置区段边界。
- 目录不能猜。正文后半段可能仍属最后一章，不能凭页码把它命名为参考文献或术语表；必须核对原页标题。
- 全局汉字替换会引入新错字，尤其“韵”“钓”。不要把某本书经验泛化为所有书规则。
- 全文字符数不等于准确度；保留所有 OCR 字符也可能错序。结构通过、OCR 覆盖率和对原图逐字准确率分别报告。
- 原页对照会明显增加文件体积；使用源 PDF 适宜分辨率，缓存图片，避免重复放入同一原页。
