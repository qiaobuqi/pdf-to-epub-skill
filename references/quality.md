# 扫描教材实证问题

- 双栏练习题中，选项 b/d 与 a/c 同行但 x 偏移。按“短行且偏离正文边缘”过滤，会无声删除正确选项。
- 全宽的章节测验横条可能只有左侧短标题被 OCR 识别；文字框不宽不代表标题不跨栏。须看原图后配置区段边界。
- 目录不能猜。正文后半段可能仍属最后一章，不能凭页码把它命名为参考文献或术语表；必须核对原页标题。
- 全局汉字替换会引入新错字，尤其“韵”“钓”。不要把某本书经验泛化为所有书规则。
- 全文字符数不等于准确度；保留所有 OCR 字符也可能错序。结构通过、OCR 覆盖率和对原图逐字准确率分别报告。
- 原页对照会明显增加文件体积；使用源 PDF 适宜分辨率，缓存图片，避免重复放入同一原页。

## 文字版复核中新增的检查

- 一套 OCR 的逐页缓存齐全、平均置信度很高，仍可能整行漏识别。对照另一套 OCR 的行框：相同高度及横向范围是否存在文字；排除已核定的图片、页眉页脚后，逐项查看原图。不能直接把另一套 OCR 的文本当作真值粘贴。
- 带大量引号的行可能触发方向分类错误。对确认漏失的行单独裁切，尝试关闭方向分类、直接行识别，再看原图确认。检查“框很宽、识别文字极少”的异常行；不要只看低置信度列表。
- 图片清单须包括未编号的照片、章节引图、发展主题小图标、封底；图表编号检查不能替代它们。侧栏正文保持文字，单独裁出侧栏内插图。表格必须检查末行、图必须检查顶部、图例和坐标轴。
- JPEG 扫描的插图可以尝试 jpegtran 无损裁剪，避免转 PNG 导致体积膨胀。MCU 对齐会调整裁剪起点，须记录实际像素坐标，并把解码后的裁图与源 JPEG 对应区域逐像素比较；不一致就回退 PNG。包内文件哈希和解码像素均须复验。
- 练习题的填空横线经常被 OCR 丢弃。用原图定位后按横坐标恢复，区分句中空格、句末空格、匹配题题号前的空格和正文破折号；不能一律在句末补横线和句号。
- 每个文字行保留源页、行号，改字和补行留独立记录。全量核对文字去向、图片引用、封面标记与目录；另做双栏顺序、跨栏总结、脚注、公式和两档字号的渲染检查。
- “所有 OCR 行都有去向”和“所有裁图像素来自原书”仍不是“全书逐字无误”。报告中必须保留这个区别，不把重建成功或 EPUBCheck 零告警写成内容零错误。
